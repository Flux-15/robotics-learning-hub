# 🤝 Contributing to the Robotics Learning Hub

First off, thank you for considering contributing to the **Robotics Learning Hub**! Our goal is to maintain the world's most rigorous, beautifully structured, and comprehensive encyclopedia and engineering blueprint repository for modern robotics.

---

## 🌟 How You Can Contribute

We welcome contributions from researchers, robotics software engineers, hardware designers, and students:
* **Add Landmark Research Reviews:** Have you read or implemented an influential paper from ICRA, IROS, RSS, or CoRL? Write a structured breakdown in `research_papers/`.
* **Add or Refine Project Blueprints:** Share open-source hardware builds, BOMs, wiring schematics, and working code in `robotics_projects/`.
* **Fix Broken Links or Outdated Information:** With fast-moving software like ROS 2 and PyTorch, keeping URLs and versions up to date is high impact.
* **Expand Cheatsheets & Code Examples:** Submit tested real-time C++ snippets, Python algorithms, or Linux system configurations in `cheatsheets/`.

---

## 📋 Contribution Guidelines

1. **Fork the Repository:** Create your own fork and create a clean feature branch:
   ```bash
   git checkout -b feature/add-new-project-blueprint
   ```
2. **Formatting & Documentation Standards:**
   * Write clean, standardized GitHub-flavored Markdown.
   * Provide **Mermaid diagrams** for system architectures, state machines, and dataflows wherever applicable.
   * Format mathematical equations using LaTeX syntax ($...$ or $$...$$).
   * Include complete Bill of Materials (BOM) with realistic pricing and voltages for all hardware project submissions.
   * Maintain cross-links and navigation breadcrumbs (`[ 🏠 Hub Home ](../README.md)`).
3. **Run Code & Verify Links:**
   * Verify that all scripts are runnable and free of syntax errors.
   * Ensure external URLs are valid and point to canonical sources (e.g. arXiv, official documentation, GitHub repositories).
4. **Submit a Pull Request:**
   * Provide a concise, descriptive title.
   * Describe what changes were made and why they add value to learners.

---

## ⚖️ Code of Conduct
Be respectful, constructive, and collaborative. We are all here to accelerate the state of robotics engineering worldwide.

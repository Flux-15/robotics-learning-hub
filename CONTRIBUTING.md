# Contributing to the Robotics Learning Hub

First off, thank you for considering contributing to the Robotics Learning Hub!

## How to Contribute
1. Fork the repository.
2. Create a new branch for your proposed addition.
3. Add your resource to the relevant `resources.md` file in the appropriate domain folder. Ensure the resource is high-quality, relevant, and correctly formatted using Markdown.
4. Submit a pull request with a brief explanation of why the resource is valuable.

## Formatting Guidelines
- Do not include emojis or informal formatting.
- Use professional documentation style.
- Maintain the existing header structure in `resources.md` files.

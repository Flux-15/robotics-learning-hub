# Robotics Learning Hub

## Introduction
Welcome to the Robotics Learning Hub! This repository serves as a comprehensive knowledge base containing structured learning resources for all major domains involved in robotics engineering. Whether you are a student starting your journey or a robotics club member looking for long-term reference material, this roadmap is designed for you.

## Domains Covered
This repository covers the following core domains required for robotics development:
- Programming and Linux
- Mathematics for Robotics
- Electronics and Embedded Systems
- Mechanical Design
- Control Systems
- Robotics Fundamentals
- ROS Ecosystem
- Simulation
- Computer Vision
- AI and Machine Learning

## Repository Structure
The repository is organized clearly by domain. Each directory contains a `resources.md` file with curated resources including:
- Official Documentation
- YouTube Lectures
- Online Courses
- Books
- Research Papers
- GitHub Repositories
- Tutorial Articles

## Learning Roadmap
Please refer to the [Robotics Roadmap](robotics-roadmap.md) for a recommended learning progression.

## How to Use This Repository
Navigate to the specific domain you are interested in and review the `resources.md` file. Each file provides highly curated resources to accelerate your learning in that specific area.

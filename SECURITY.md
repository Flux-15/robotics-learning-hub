# Security Policy

## Supported Versions

We actively maintain and provide updates for the latest revision on the `main` branch.

| Branch | Supported |
| :--- | :---: |
| `main` | :white_check_mark: |
| Other tags / older commits | :x: |

## Reporting a Vulnerability

The Robotics Learning Hub takes security, hardware safety, and electrical guidelines seriously. 

If you discover a vulnerability, dangerous electrical or battery instruction, or security loophole in any code or schematic:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to **[omspatel15@gmail.com](mailto:omspatel15@gmail.com)** with the subject line `[SECURITY] Robotics Learning Hub Report`.
3. Include details of the file, line number, potential risk, and recommended remediation.
4. We will acknowledge receipt within 48 hours and work with you to publish a fix promptly.

Thank you for helping keep the robotics engineering community safe!

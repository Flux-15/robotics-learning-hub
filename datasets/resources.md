# Datasets for Robotics

## Overview
Training data is the fuel for machine learning models. Robotics requires datasets encompassing perception (images, LiDAR point clouds), kinesthetic demonstrations, and synthetic simulation data.

## Major Autonomous Driving and Localization Datasets
- [KITTI Vision Benchmark Suite](http://www.cvlibs.net/datasets/kitti/): Foundational dataset for autonomous driving (stereo, optical flow, visual odometry, 3D object detection).
- [NuScenes (by Motional)](https://www.nuscenes.org/): Multimodal dataset with cameras, radar, and lidar.
- [Waymo Open Dataset](https://waymo.com/open/): Extremely high-quality autonomous driving dataset.
- [Oxford RobotCar Dataset](https://robotcar-dataset.robots.ox.ac.uk/): Long-term autonomy dataset driven through Oxford.

## General Computer Vision & Deep Learning Datasets
- [COCO (Common Objects in Context)](https://cocodataset.org/): Object detection, segmentation, and captioning.
- [ImageNet](http://www.image-net.org/): Standard classification benchmark.
- [Pascal VOC](http://host.robots.ox.ac.uk/pascal/VOC/): Foundational computer vision dataset mapping.

## Manipulation and Grasping Datasets
- [DexNet (Dexterity Network)](https://berkeleyautomation.github.io/dex-net/): Dataset of 3D models and parallel-jaw grasps.
- [RoboNet](https://www.robonet.wiki/): Large-scale multi-robot dataset for learning robot manipulation.

## Indoor Navigation Datasets
- [Matterport3D](https://niessner.github.io/Matterport/): RGB-D indoor environment dataset.
- [Gibson Environment Database](http://gibsonenv.stanford.edu/database/): Diverse real-world indoor spaces.

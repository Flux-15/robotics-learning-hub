# 📟 Embedded Systems Resources

> [!TIP]
> For the comprehensive engineering manual on microcontrollers (STM32, ESP32, Teensy, RP2040), CAN bus protocol, FreeRTOS architecture, and micro-ROS setup, see the **[Embedded Systems Guide](README.md)**.

## Overview
Embedded systems bridge software and hardware. Microcontrollers read sensor data via SPI/I2C/CAN and command actuators in real-time with microsecond determinism.

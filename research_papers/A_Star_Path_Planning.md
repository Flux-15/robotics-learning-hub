# A Formal Basis for the Heuristic Determination of Minimum Cost Paths

**Authors:** Peter E. Hart, Nils J. Nilsson, Bertram Raphael

**Publication:** IEEE Transactions on Systems Science and Cybernetics (1968)

**Paper Link:** [A Formal Basis for the Heuristic Determination of Minimum Cost Paths](https://ieeexplore.ieee.org/document/4082128)

## Summary
The foundational paper for the A* search algorithm, describing how heuristics can be combined with formal cost-based search to efficiently find optimal paths in a graph.

## Applications
Global path planning, video game AI, routing networks.

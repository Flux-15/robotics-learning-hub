# Rapidly-Exploring Random Trees: A New Tool for Path Planning

**Authors:** Steven M. LaValle

**Publication:** Technical Report, Computer Science Dept, Iowa State University (1998)

**Paper Link:** [Rapidly-Exploring Random Trees: A New Tool for Path Planning](http://msl.cs.uiuc.edu/~lavalle/papers/Lav98c.pdf)

## Summary
Introduces Rapidly-exploring Random Trees (RRTs), a randomized data structure designed for efficient search in high-dimensional continuous spaces, specifically handling nonholonomic constraints.

## Applications
Robotic manipulator motion planning, autonomous driving in complex environments.

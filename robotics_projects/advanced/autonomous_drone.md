# Autonomous Drone

## Project Overview
A detailed guide and documentation for building the Autonomous Drone.

## Hardware Components
Flight Controller (Pixhawk), Companion Computer (Jetson Nano/Raspberry Pi), Depth Camera.

## Software Stack
ROS, PX4/ArduPilot, MAVROS, OpenCV

## Implementation Steps
1. Configure flight controller. 2. Establish MAVLink communication via MAVROS. 3. Implement offboard control. 4. Integrate vision processing for obstacle avoidance or precision landing.

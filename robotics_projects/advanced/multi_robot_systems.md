# Multi-Robot Systems

## Project Overview
A detailed guide and documentation for building the Multi-Robot Systems.

## Hardware Components
Multiple mobile bases (e.g., TurtleBot 3), Central Network Infrastructure.

## Software Stack
ROS 2, DDS, Fleet Management Software

## Implementation Steps
1. Assign distinct ROS domains/namespaces. 2. Ensure network connectivity. 3. Implement decentralized or centralized task allocation. 4. Coordinate movements to prevent collisions.

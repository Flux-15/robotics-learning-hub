# Line Following Robot

## Project Overview
A detailed guide and documentation for building the Line Following Robot.

## Hardware Components
Arduino Uno, L298N Motor Driver, IR Sensor Array, DC Motors, Chassis.

## Software Stack
C++ (Arduino IDE)

## Implementation Steps
1. Assemble chassis. 2. Mount and wire components. 3. Read IR sensor values. 4. Implement proportional control to drive motors based on error.

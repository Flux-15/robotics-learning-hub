# Obstacle Avoidance Robot

## Project Overview
A detailed guide and documentation for building the Obstacle Avoidance Robot.

## Hardware Components
Arduino Uno, Ultrasonic Sensor (HC-SR04), Servo Motor, L298N, DC Motors.

## Software Stack
C++ (Arduino IDE)

## Implementation Steps
1. Connect ultrasonic sensor. 2. Write function to measure distance. 3. Implement logic: advance if path is clear, stop and turn if distance < threshold.

# Maze Solving Robot

## Project Overview
A detailed guide and documentation for building the Maze Solving Robot.

## Hardware Components
Microcontroller, Advanced IR Array, Encoders, Drive Base.

## Software Stack
C++, PID Control, Graph Algorithms

## Implementation Steps
1. Implement accurate PID wheel control. 2. Read sensor array for wall detection. 3. Implement Left-Hand or Right-Hand rule logic. 4. (Extension) Implement memory to optimize the second run.

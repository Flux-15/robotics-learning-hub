# SLAM Robot

## Project Overview
A detailed guide and documentation for building the SLAM Robot.

## Hardware Components
Raspberry Pi, 2D LiDAR (e.g., RPLidar), Odometry sources.

## Software Stack
ROS, Python/C++, Hector SLAM or Gmapping

## Implementation Steps
1. Configure ROS environment. 2. Set up URDF and tf tree. 3. Interface LiDAR and publish LaserScan messages. 4. Launch SLAM node to build a 2D map.

## Overview
Practical implementation is crucial in robotics. This directory contains structured project documentation ranging from beginner microcontroller tutorials to advanced system integrations with ROS 2, PX4, and Embodied AI.

## Major Open-Source Hardware Projects to Reference
- [Hugging Face LeRobot (SO-ARM100 & Koch Arm)](https://github.com/huggingface/lerobot) — Open-source low-cost robotic arms for imitation learning
- [Open-Dynamic-Robot-Initiative (ODRI)](https://open-dynamic-robot-initiative.github.io/) — Open-source torque-controlled quadruped and bipedal robots
- [Stanford DogGo & Pupper](https://github.com/stanfordstudentrobotics) — Accessible quadruped locomotion platforms
- [TurtleBot 4](https://clearpathrobotics.com/turtlebot-4/) — Official ROS 2 reference mobile robot platform by Clearpath Robotics / Open Robotics
- [PX4 Autopilot](https://px4.io/) — Industrial-grade open-source flight stack for autonomous drones

# Robot Operating System (ROS) Resources

## Overview
ROS (and ROS 2) is the industry standard middleware for robotics. It provides message-passing architectures, hardware abstraction, and vast libraries for planning, perception, and navigation.

- [ROS 2 Documentation](https://docs.ros.org/)
- [Navigation 2 (Nav2) Docs](https://navigation.ros.org/)
